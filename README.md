# UK TV Patches

[Add UK TV Patches to Morphe](https://morphe.software/add-source?github=pholcroft/uk-tv-morphe-patches&name=UK%20TV%20Patches)

Open the link on your Android phone with Morphe Manager installed and tap **Add** in Morphe.

This independent compatibility source currently supports the BBC iPlayer Android TV app, version **1.0.1 (101)**, for use in the UK. BBC sign-in, geographic checks and DRM still apply.

[Download the APK through Aurora Store and patch it on your phone](https://github.com/pholcroft/morphe-androidtv-patches/blob/feat/bbc-iplayer-1.0.1-preview/docs/bbc-iplayer/walkthroughs/README.md).

This repository distributes the [compatibility patch source](src/StreamerCompatibilityPatch.kt) and the compiled Morphe patch. Obtain the original app separately. The full [source tree for this patch build](https://github.com/pholcroft/morphe-androidtv-patches/tree/acc875bc9ec0371f4eb1fd42bf8eed597f805781) includes the build configuration.
